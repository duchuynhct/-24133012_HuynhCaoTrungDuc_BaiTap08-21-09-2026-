1. Sắp xếp giá từ thấp đến cao
query {
  productsByPriceAsc {
    id
    title
    price
    quantity
    category {
      name
    }
  }
}
2. Lấy sản phẩm của 01 danh mục
query {
  productsByCategory(categoryId: 1) {
    id
    title
    price
    category {
      name
    }
  }
}
3. Thêm mới sản phẩm (Mutation)
mutation {
  createProduct(input: {
    title: "Tai nghe AirPods Pro 2"
    quantity: 20
    price: 5990000
    description: "Chống ồn chủ động ANC"
    categoryId: 1
  }) {
    id
    title
    price
  }
}
4. Thêm danh mục mới (Mutation)
mutation {
  createCategory(input: {
    name: "Đồng hồ thông minh"
    images: "smartwatch.jpg"
  }) {
    id
    name
  }
}
